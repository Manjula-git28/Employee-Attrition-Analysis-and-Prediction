# Employee-Attrition-Analysis-and-Prediction
Employee turnover is a critical challenge for organizations, leading to increased recruitment costs, productivity loss, and workforce instability. This project focuses on analyzing employee data, identifying key drivers of attrition, and building predictive machine learning models to proactively identify employees at risk of leaving.
# Employee Attrition Analysis and Prediction

## Project Overview
This project analyzes employee data to understand the key factors behind employee attrition and builds a machine learning model to predict employees who are at risk of leaving the organization.

## Problem Statement
Employee turnover increases hiring costs and reduces productivity. This project helps HR teams predict attrition early and take preventive actions.

## Domain
HR Analytics

## Business Use Cases
- Identify employees at risk of attrition
- Improve employee retention strategies
- Reduce recruitment and training costs
- Support HR decision-making

## Skills & Tools
- Python
- Pandas, NumPy
- Exploratory Data Analysis (EDA)
- Machine Learning (Classification)
- Scikit-learn
- Streamlit
- GitHub

## Project Steps
1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature engineering
4. Model building (Logistic Regression, Random Forest)
5. Model evaluation (Accuracy, Precision, Recall, F1-score, AUC-ROC)
6. Streamlit dashboard for visualization and prediction

## Dataset
Employee Attrition dataset containing employee demographics, job details, satisfaction metrics, and performance information.

## Model Output
- Attrition prediction (Yes / No)
- Attrition probability score

## Results
- Achieved more than 85% accuracy
- Identified key attrition drivers such as job satisfaction, overtime, and income

## Tools Used
Python, Scikit-learn, Streamlit

## Conclusion
The project provides a predictive solution for HR teams to identify at-risk employees and improve retention strategies.
